Welcome to MCQ Quiz Application

MCQ Quiz Application is an online examination platform where users can attempt quizzes and get instant results.

This system is designed to simplify online tests by providing automatic evaluation and quick feedback.

Application Features

  • User registration and secure login
  • Admin can add and manage questions
  • Multiple-choice questions (MCQ)
  • One-time quiz attempt per user
  • Instant result with score and percentage

Get Started

New users can register and start the quiz. Admins can log in to manage questions and view results.
