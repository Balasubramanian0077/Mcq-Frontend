Help & Support

This page provides guidance on how to use the MCQ Quiz Application effectively.

For Users

  • Register using a valid email address.
  • Login with your registered email and password.
  • Read instructions carefully before starting the quiz.
  • Answer all questions before submitting.
  • You can attempt the quiz only once.

For Admin

  • Login using admin credentials.
  • Add new quiz questions.
  • View all questions and user results.

Common Issues

  • Login failed: Check your email and password.
  • Quiz not loading: Ensure the backend server is running.
  • Already attended test: You cannot retake the quiz.

If problems persist, please contact the system administrator.
