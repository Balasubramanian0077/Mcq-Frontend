About MCQ Quiz Application

The MCQ Quiz Application is a web-based system developed to conduct online multiple-choice quizzes in a simple and efficient manner.

This application helps users to attend quizzes and get instant results, while administrators can manage questions and monitor results.

Key Features

  • User registration and secure login
  • Admin can add and manage quiz questions
  • One-time quiz attempt for users
  • Automatic evaluation of answers
  • Instant result with score, percentage and grade

Technologies Used

  • Frontend: HTML, CSS, JavaScript
  • Backend: Spring Boot (REST API)
  • Database: MySQL

This project is developed for academic and learning purposes.
